MediaOS
Quick-start guide & control panel reference

First run

  1. Double-click Start-MediaOS.bat to open the Control Panel.
  2. Pick a stack from the Stack dropdown (leave it on the default unless you need standalone/GPU-transcode profiles).
  3. Click Start MediaOS. On the very first run this also creates .env from .env.example and generates a database password for you.
  4. Wait ~10–20 seconds for containers to come up, then click Health Check to confirm everything's green.
  5. Click Open MediaOS UI to start managing your library.

Troubleshooting

  • Health Check shows "UNREACHABLE" — the app container may still be starting, or Docker Desktop isn't running. Check View Logs.
  • Start fails immediately — make sure Docker Desktop is installed and running; the script checks for docker on PATH first.
  • Forgot your database password — it's in .env under POSTGRES_PASSWORD; open it with Edit .env.
  • Need to rebuild from source instead — see scripts\windows\dashboard.bat, the developer build/test dashboard.
