MediaOS is the UI
One user experience ≠ one process. MediaOS is the brain. Jellyfin streams, qBittorrent downloads, Gluetun tunnels, Tdarr transcodes, Redis & Postgres persist — each in its own container, glued by Docker Compose, orchestrated by MediaOS.

Architecture A single FastAPI control plane over modular containers

MediaOS Next is a single FastAPI application (592 routes, 45 routers, 75 services) that implements — natively, in its own codebase — what each *arr app does as a separate binary. Supporting infrastructure stays in dedicated containers, glued together by Docker Compose and orchestrated by MediaOS.

VPN kill-switch No VPN = no downloads. Nothing leaks your real IP.

┌──────────┐ ┌──────────┐ ┌────────────┐ ┌──────────┐ │ Indexer │────▶│ MediaOS │────▶│ qBittorrent│────▶│ Gluetun │──VPN──▶ Internet │ search │ │ (grab) │ │ network_ │ │ (tunnel) │ └──────────┘ └──────────┘ │ mode: │ └──────────┘ │ service: │ │ gluetun │ └────────────┘
How it works: qBittorrent uses network_mode: "service:gluetun", sharing Gluetun's network namespace. It has no network interface of its own. If the tunnel drops, qBittorrent loses all connectivity — downloads stall, nothing leaks. No iptables rules, no race conditions, just namespace isolation. MediaOS monitors Gluetun's control server and reports VPN status + expected country in the UI.

Quick start Three commands to a running stack

1

Clone & configure

Copy the environment template and generate required secrets (Postgres password + auth API key).

2

Edit .env

Set library host paths, VPN credentials, qBittorrent login, TMDB API key and timezone.

3

Launch

docker compose up -d then open http://localhost:8787 — the first-run wizard does the rest.

# 1. Clone & configure
git clone https://github.com/newguy467/MediaOs.git mediaos-next
cd mediaos-next
cp .env.example .env
bash scripts/generate_secrets.sh   # POSTGRES_PASSWORD + AUTH_API_KEY

# 2. Edit .env: set library paths, VPN creds, TMDB_API_KEY, TZ

# 3. Launch the stack
docker compose up -d               # core stack
# docker compose --profile tdarr up -d   # + transcoding farm
# docker compose --profile full up -d    # + EPG + FlareSolverr + Ollama

# Open http://localhost:8787 → first-run wizard
Then: Discover → add media → MediaOS searches indexers → grabs via qBittorrent (through VPN) → imports to library → Jellyfin streams it.
