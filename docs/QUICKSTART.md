# mediaos — first 10 minutes

1. **Start the container** with volumes (see README Docker volumes).
2. Open the UI → **Setup wizard** (or `/` first-run).
3. Enter **TMDb** (and optional TVDB) API keys.
4. Set **library paths** (movies/tv/music/books) matching your mounts.
5. Connect **qBittorrent** (or Transmission/Deluge/…) URL + credentials.
6. Optional: **Jackett** URL + API key → Sync indexers.
7. Finish wizard → **Discover** → add one movie → confirm it hits the Queue.
8. Optional: **Settings → Integrations → TRaSH** (bundled packs) and **DB migrator** for *arr import.
9. Open **History** and **Logs** if something fails — Logs is under advanced nav.

Day-to-day: Discover/add → automatic search → Queue → import to library → History.
